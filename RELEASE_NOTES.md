## What's new in 0.7.3

- **Chat list by latest message.** The chat with the newest message is at the top, in the corner chat and in full screen, instead of a fixed order.
- **Edit your name.** The Profile page has an "Edit name" button, so a name that was typed as a first name only can be changed to your full name (it is used in the sidebar and in your documents).
- **Delete a user, safely.** The Profile page has "Delete this user…". It asks twice, and the second time you must type the user's name, so a wrong click cannot do it. Nothing is erased: the folder moves to "_Deleted_Users" next to it and can be moved back by hand.
- **Fixes "agent 'raka' not found".** On folders that were set up by hand or from an older kit, the chats of Raka, Laras and the Applications team could not start. Vantage now puts the missing agent files in place before a chat runs (nothing that exists is overwritten).
- **Asking Nova to tidy the Inbox now works.** Nova cannot move files in a chat, by design; instead of a dead end it now offers a "Tidy up my Inbox" button that runs the safe Tidy up.
