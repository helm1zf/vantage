## What's new in 0.7.4

- **Profile page fixed.** The Raka chat that had been placed in the middle of Profile is removed; it pushed the other cards over each other. Raka is in the corner chat like the others.
- **A busy chat no longer shows an error.** If a long request (for example updating the Master CV) is still running and you send another message, the chat now says it is still working and finishes by itself, instead of "Still answering in this chat."
